# Pi Bot for Mac 需求与验收

## 定位

Mac 端只是 Bot 的工作电脑（harness）：登录、显示 Bot、让 Bot 在本机资料库里干活。不提供编程项目、代码 diff、浏览器自动化、Skills 管理界面、MCP，也不让用户配置模型。Skills 由每个 Bot 通过内置 Pi Extension 自行管理，云端统一保存，详情见 [agent/README.md](../packages/agent/README.md)。

## 功能需求

| 编号 | 需求 | 验收 |
|---|---|---|
| M1 | 用管理员创建的账号登录；登录将本机添加为账号可用电脑，Bot 不绑定机器 | 错误密码有中文提示；多台电脑可同时在线，新任务按来源偏好和能力独立选择机器 |
| M2 | 账号凭据只存设备私钥，不存用户密码和用户令牌 | `account.json` 无令牌；私钥在钥匙串或 0600 的 `secrets.json` |
| M3 | Bot 列表显示名字、表情、最近消息、待审批红点 | 运行中显示「工作中」，有审批显示「等你批准」，3 天以上无活动显示「睡着了 · N 天」 |
| M4 | 新建 / 编辑 / 归档 Bot：名字、人设、模型、造型、颜色、深浅色 | 预览实时变化；新建后 `~/pi-bot/<slug>/` 出现；归档不删文件 |
| M5 | 每个 Bot 一条时间线，支持即时短回复、Markdown、异步任务 | 长任务先发具体短句，再独立给进展和结果；默认用日常语言，结果 1–3 条短消息，细节按需展开；私有技能与记忆说明隐藏；回复按段持久化并去重；执行状态显示当前任务，结束后自动清除；前台在线每 5 秒核对（空闲也核对），重连与回到前台重新刷新 |
| M6 | Bot 能在资料库里列目录、读、写、改、搜索文件和执行命令 | 让 Bot 写一个文件，Finder 里能看到；命令超时会被终止 |
| M7 | 资料库以外的访问必须经用户批准 | 未批准前读取 `~/Desktop` 失败；批准后本次任务可读，下一次任务需要重新申请 |
| M8 | 手机可浏览 Mac 在线时的资料库 | 手机列目录、看文本和图片；Mac 离线时提示不可用 |
| M9 | Mac 断网 / 退出时不丢消息 | 运行中的任务标为失败并提示可重发；对话始终在云端，后续任务重新选择可用机器 |
| M10 | 「在 Finder 中打开资料库」 | 打开 `~/pi-bot/<slug>/` |
| M11 | Bot 委托显示本次双方传话详情 | 主聊天显示「X 条消息往来 · 对方 · 状态」；点击打开本次委托原文、补充、公开进展及结果，显示双方头像、方向与时间，支持分页、重试和跳转聊天；只统计执行方的运行状态，同步等待父任务不显示为执行中 |

## 非功能需求

- 本机不保存模型 API Key；模型调用只经云端代理，令牌默认 15 分钟有效，运行中每 10 分钟自动刷新。
- 所有云端请求带设备签名，时间戳 ±5 分钟、nonce 不可重放。
- 文件工具解析符号链接，不能借链接越过资料库；拒绝授权 `/` 和整个家目录。
- 命令输出只保留尾部 30KB，取消时结束整个进程组。
- Pi 私有状态按 Bot ID 隔离；内部 skills 不写入可浏览资料库，不扩大现有审批权限。
- 界面中文；角色动画遵守系统「减少动态效果」。

## 自动化测试

- `desktop/tests/library.test.ts`：资料库命名、沙箱越界与符号链接、文件工具、命令超时与取消、外部访问审批、手机预览。
- `desktop/tests/harness-e2e.test.ts`：真实 Pi Bot 服务器 + 真实 Pi agent + 脚本化模型服务，覆盖登录绑定、Mac 上运行工具写文件、手机浏览文件、外部访问审批后继续、云端对话、按任务选机与退出登录后的资源约束。

- 每个 Bot 最多两个后台执行；同一资料库写文件和命令共用可取消的锁，审批期间不持锁。对话完成不清除其他任务的活动表情；发送失败保留输入并使用相同请求 ID 重试。


### Always-on 验收

- 聊天可建立、查询、修改、暂停、恢复、完成和停止目标；没有进行中的目标时不自动检查。进度、检查点和重连唤醒均持久化。
- 每轮按保存的策略选择兼容电脑或云端机器，不委托其他智能体；断线续接保存进度，未确认副作用等待用户。
- 没有新进展保持静默，有进展的目标在现有时间线各发一条且不重复；等待不占执行名额，静默轮次不改变列表活跃时间。
- 检查可在目标授权范围内改文件和跑命令；控制版本、调用次数、每日八轮上限及失败退避由服务端执行。
