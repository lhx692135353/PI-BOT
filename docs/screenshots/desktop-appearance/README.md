# 桌面外观预览

以下截图来自真实桌面 React 界面，使用模拟账号、设备、资料和对话，不连接真实服务器。

- [浅色主题](light.png)：侧栏搜索、彩色头像和聊天输入框。
- [深色主题与目标侧栏](dark.png)：在宽窗口中独立显示目标面板。
- [窄窗口](dark-narrow.png)：900 × 700 窗口内的聊天布局。
- [头像编辑器](dark-editor.png)：八种彩色选项，头像独立于界面主题。
- [白橙应用图标](app-icon.png)：白色底座、橙色小人近景。

已在 Electron 中检查主题切换与重载记忆、搜索与清除、快捷键、目标/资料库切换、面板关闭及窄窗口横向溢出。
