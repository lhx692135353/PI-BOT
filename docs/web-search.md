# 联网搜索

后台任务通过同一个 `web_search` 工具检索，返回标题、链接和摘要。对话需要搜索时会安排后台任务。模型密钥只保存在服务端。

## 配置模型原生搜索

在管理后台的模型管理页添加或编辑模型，开启「用作联网搜索」并保存。xAI、百炼和自定义模型都支持此配置，默认关闭；开启前需确认服务商支持这项能力。

自定义模型填写 Responses API Base URL（例如 `https://gateway.example.com/v1`）、模型 ID 和 API Key。搜索请求发送到该地址的 `/responses`，携带 `tools: [{"type":"web_search"}]` 和 `tool_choice: "required"`，要求模型实际检索。网关及该模型都必须支持 Responses API 原生搜索，并在响应中返回状态为 `completed` 的 `web_search_call`。仅支持 Chat Completions 或普通函数调用的模型不满足此要求；系统不会把普通生成的回答当作已联网搜索。

结果沿用现有来源链接校验、去重和长度限制。模型返回结构化结果时使用其中的标题、链接和摘要；只返回带引用的文本时，使用引用链接及精简总结。搜索 token 用量计入所选搜索模型，相同模型、查询和语言的成功结果缓存五分钟。

## 后端优先级

通过服务端环境变量 `PI_BOT_SEARCH_BACKEND` 设置：

| 值 | 行为 |
| --- | --- |
| `auto`（默认） | 配置了 Tavily 时优先使用 Tavily，否则使用已启用原生搜索的模型 |
| `tavily` | 仅使用 Tavily，需要配置 `PI_BOT_TAVILY_API_KEY` |
| `provider` | 仅使用模型原生搜索，即使配置了 Tavily |

候选搜索模型必须同时启用模型和「用作联网搜索」。多个候选中优先默认模型，再按创建时间选择。任务的对话模型与搜索模型可以不同。

搜索失败或 Tavily 额度耗尽时，不自动切换到另一后端。上游拒绝请求时，任务会看到 HTTP 状态及检查模型能力、密钥或权限的提示；自定义模型没有完成原生搜索时会明确报错。上游原始错误正文和凭据不会出现在搜索结果中。已完成搜索但没有可用来源时，返回空结果及提示。
