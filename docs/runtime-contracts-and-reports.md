# 自主执行、结构化回执与报告文件

目标是让智能体像可靠的同事：理解上下文，自主使用工具，先做再报告事实。普通聊天简短；适中的解释可以有表格、代码；需要独立阅读、保存的长报告交付文件。长度和措辞都不作为意图分类器。

## 执行与协作

删除 execution-receipts 的中文/英文承诺、完成、转发等短语匹配和自动纠正轮次。工具由模型原生选择，不新增逐轮规划器、裁判模型或词表路由。后台任务、智能体委托、补充要求和取消继续使用原有鉴权与幂等 API。

共享 `packages/runtime-contracts` 注册工具的读写效果、公开程度、活动显示、内部归属，未知工具不获得读写权限。实际工具清单保存到 `bot_runs.tool_manifest`；调用生命周期保存到 `action_receipts`，可携带资源和目标 ID。调用结束只表示工具返回，任务是否完成仍看任务状态；queued/pending 不代表执行或答复。

聊天只调度，执行放到后台。清除对模型回答措辞的强制校验。显式 `send_reply` 的 answer 是回复来源，模型最终文本只作后备，不比较文字决定是否重复。展示按消息 ID 和 phase，不按自然语言猜进度。

## 模型与错误

对话与模型等待上限均为十分钟，明确更早的任务截止时间优先。模型能力保存在配置中，支持原生工具、图片和推理参数由能力声明决定，不按 Qwen/Grok 等名称正则猜测。管理端可以设置能力和服务商关闭推理参数；未确认的推理能力遵循服务商默认。无列表 API 的 Token Plan 目录移至版本化 JSON 种子；仍允许填写其他模型 ID。

跨 HTTP、本地 IPC、Electron 和手机 RPC 传递 `error_info`：code、scope、retryable、outcome、message。控制逻辑使用 code，message 仅用于阅读。SSH 中断保留结果未知，不因此重放写操作。手机预览和会话不再按“失效、离线、超时”等提示文字分类。

## 报告与上下文

`publish_report` 在已授权后台任务中保存 UTF-8 Markdown。正文持久化在 PostgreSQL `report_artifacts.body`；上限 10 MiB；(run_id, call_id) 幂等。消息通过 `message_artifacts` 关联文件元数据，不保存正文副本。任务完成、委托回报、检查点结果使用简短摘要与文件引用。

桌面和 Android 展示标题、文件类型、大小及打开入口。服务端校验用户归属后签发五分钟文件票据。浏览器本地 Markdown 渲染，支持表格和代码；可以下载，打开文件不触发模型调用。票据经 URL fragment 传递并清除；内容响应 no-store，预览禁用原始 HTML。

写入工具的报告正文从后续模型上下文和诊断中剥离。聊天、回报、长期记忆和历史检索的源消息只保留摘要及引用。需要分析文件时使用 `report_read` 明确读取片段，每次最多 4000 字符；不默认加载整份文件。正文不依赖本机资料库，因此重启、切换电脑后仍可读取。

默认保留最近六个完整轮次，历史文字约 4000 token，记忆约 1500 token，任务状态约 1000 token，普通输入目标 16000 token。历史图片另外计入窗口和传输限制。当前用户输入和安全指令不截断；超出可用窗口时保留原始记录并允许检索。裁剪提示放系统上下文，不能改写用户原文。

记忆是带来源的资料，不是系统指令。删除用威胁短语判定语义和主题含数字即拒绝的规则；记忆查找保留完整规范化内容，不再剥掉看起来像展示前缀的正文。凭据格式检测仅是补充检查，未命中不代表内容安全；鉴权、归属、路径隔离和读写权限仍是实际边界。保留协议字段、状态机、路径校验、坐标范围等结构约束。

## 验证和发布

协议测试使用隔离数据库和脚本模型，覆盖持久化、幂等、访问控制、调度、历史、事件、文件预览。此类测试不能证明模型自主调用能力。桌面文件卡片需要宽/窄窗口和点击验证；Android 需要编译及单测；Windows/Linux 行为以对应 CI 验证。

真实模型评测入口：`node --import tsx scripts/evals/agent-behavior.ts`。显式设置 PI_BOT_EVAL_BASE_URL、PI_BOT_EVAL_API_KEY、PI_BOT_EVAL_MODEL；不发现或借用生产凭据。30 个场景各跑三次，使用隔离工具替身，不向真实智能体发消息或执行命令。输出结构检查和原始答复，另由人审阅误报、漏调用、重复、表达和不必要澄清；不能用结构检查替代模型质量判断。

当前环境没有配置真实模型评测的端点、模型和密钥，因此这 90 次真实模型评测尚未运行。合并前应补齐结果；不能把脚本模型测试包装成 Qwen 实测。服务端迁移、共享 Agent、Mac/Windows/Linux 安装包和 Android 需要同批升级，旧客户端无文件卡片支持。变更通过原 PR 审查，未经请求不合并或部署。
