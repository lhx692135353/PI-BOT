# Pi Bot iOS 需求与验收

整体架构见 [server/ARCHITECTURE.md](../server/ARCHITECTURE.md)。功能编号与 [Android 需求](../android/REQUIREMENTS.md) 对应。

## 定位

iPhone 与 iPad 上的 Bot 遥控器，和 Android 客户端同等能力（虚拟手机除外）。手机本身不运行 agent，不配置模型，也没有本地数据库。

## 技术栈

- Swift 5 语言模式、SwiftUI、Observation，最低 iOS 17。
- `URLSession`（REST + 前台 WebSocket），钥匙串保存会话。
- 角色：`PiBotKit/Face` 是 `packages/bot-face` 的移植，同一种子与 TypeScript、Android 逐帧一致；`spec.json` 在构建时复制进 App。
- A2UI：`WKWebView` 加载打包的 `packages/a2ui` 渲染器，自定义 `pibot-ui://` scheme 只提供三份静态资源。
- 语音：`AVAudioEngine` 开启系统语音处理（回声消除），16 kHz 单声道 PCM16 收发，与 Android 协议相同。请求中 `client` 为 `ios`。

## 功能需求

| 编号 | 需求 | 验收 |
|---|---|---|
| A1 | 服务器地址 + 账号登录 | 地址可带路径前缀；支持 HTTP、HTTPS；错误密码、连不上服务器有中文提示 |
| A2 | Bot 会话列表 | 主 Bot 入场动画、搜索、最近时间、状态一句话、待审批红点、电脑在线状态；下拉刷新；紧凑宽度单页切换，常规宽度（iPad、大屏横屏、分屏较宽时）左列表右对话且高亮选中项，默认选中主 Bot；切换 Bot 和调整窗口保留草稿 |
| A3 | 新建 / 编辑 / 归档 Bot | 预览实时变化，可「随机换一个」；模型可选「跟随默认」；归档前二次确认 |
| A4 | 时间线 | Markdown（标题、列表、引用、代码、表格、链接）可部分选择复制；回答上方最多三句进度；滚到顶部加载更早消息且保持位置；图片、报告附件、委托标签与传话详情；A2UI 交互 |
| A5 | 审批卡片 | 拒绝、仅本次允许、一直允许（二次确认）；结果后卡片消失 |
| A6 | 资料库浏览 | 选择文件来源，逐级进入目录与返回上一级；文本、Markdown、图片预览；离线提示 |
| A7 | 设置 | 账号、服务器、实时连接、执行电脑与解绑、修改密码（至少 8 位）、退出登录、已保存授权与日志 |
| A8 | 实时更新 | 前台保持 WebSocket，断线退避重连并补拉；进入后台断开；会话失效回到登录页 |
| A9 | 语音通话 | 麦克风权限说明；免提与回声消除；静音、挂断、计时；插话打断；后台继续；15 秒内断线续接；另一设备或另一对话通话时提示 |
| A10 | 图片 | 最多 4 张，单张 ≤ 2 MB、合计 ≤ 4 MB；不支持的格式或过大的照片转为 JPEG |

## 非功能需求

- 令牌只存在钥匙串里；不保存密码。
- 界面中文，固定浅色主题；系统开启「减弱动态效果」时角色保持静止。
- iPhone 支持竖屏与横屏，iPad 支持全部方向、分屏与台前调度。
- 不提供系统推送和应用内更新。

## 自动化测试

`cd ios/PiBotKit && swift test`：

- `FaceTests`：规格列表、Mulberry32、`avatarFor`、`seedOf`、轮廓平滑、引擎帧与 TypeScript 参考值一致、减弱动态效果、运行状态到表情的映射。
- `DomainTests`：时间线合并与 `delta`、运行中工具与后台活动对表情的影响、状态一句话、委托标签、服务器地址解析、Markdown 块与行内解析、消息文档保留链接与代码原文。
- `StoreTests`（`URLProtocol` 桩）：登录与路径前缀、错误信息、Bot/消息/发送/分页、编辑时总是带上 `model_id`、资料库路径编码与离线提示、401 自动登出、已保存授权、通话事件对本机与其他设备通话的处理。
