# Pi Bot 云端需求与验收

整体架构见 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 定位

多用户的 Bot 后端：保存用户、Bot、时间线、记忆、审批和用量；把运行路由到用户的 Mac 或云端；统一代理模型调用。模型和用户只由管理员配置。

## 功能需求

| 编号 | 需求 | 验收 |
|---|---|---|
| S1 | 首个管理员来自环境变量；管理员创建、修改、禁用、删除用户；没有注册接口 | 用户名不区分大小写唯一；禁用后该用户的令牌立即 401 |
| S2 | 管理员增删改模型、设默认、测试连通 | 第一个模型自动成为默认；删除模型后用它的 Bot 改用默认模型；接口从不返回 API Key |
| S3 | 普通用户只能看到模型名称和是否默认 | `/models` 不含地址、服务商模型名和 Key；`/admin/api/*` 返回 403 |
| S4 | 每个用户最多绑定一台 Mac；新绑定吊销旧设备 | 旧设备签名请求 401，旧连接以 4401/4409 关闭 |
| S5 | Bot 增删改查，按用户隔离；资料库 `slug` 由名字生成、同用户内唯一、改名不变 | 其他用户访问任何 Bot 相关接口返回 404 |
| S6 | 发消息幂等，对话与后台任务独立 | 重复请求返回同一个运行；忙时仍接受消息并排队；每 Bot 一个对话回合、两个后台名额；没有模型返回 503 |
| S7 | Mac 在线时运行下发到 Mac，离线时由 Worker 在云端运行 | 云端运行不带文件和命令工具，系统提示说明 Mac 离线 |
| S8 | 文本推送给手机和 Mac，落库节流，过滤私有能力管理说明 | 启用私有 skills 的会话先分类完整模型消息再推送，不逐 token 展示内部说明；未启用时保留流式推送；落库每秒最多一次 |
| S9 | 停止运行 | Mac 运行收到 `cancel`；排队中的运行立即取消；执行中的云端运行被中止 |
| S10 | Mac 中途掉线或 API 重启，Mac 运行标为失败 | 状态 `failed`，保留已生成文本，提示可重新发送 |
| S11 | 资料库以外访问的审批：创建、批准/拒绝、过期 | 运行进入 `waiting_approval`；决定转发给 Mac；过期或重复决定返回 409 |
| S12 | 手机浏览 Mac 上的资料库 | 经 Mac 转发；Mac 离线 503，超时 504 |
| S13 | 模型代理：Responses API 兼容、流式、注入服务商 Key、记录用量 | 只接受代理令牌；转发时 `model` 改为服务商模型名；用量按用户、模型、来源统计 |
| S14 | 长期记忆：时间线超过阈值后压缩较早的消息 | 摘要进入后续运行的系统提示；压缩失败不影响对话 |
| S15 | 管理后台：概览、用户、模型、Mac 设备（含吊销）、用量 | 吊销后设备立即无法访问 |
| S16 | 异步任务与跨 Bot 协作 | 对话仅调度，后台独立执行；支持查询、补充和明确取消；任务内记录隐藏，完成后独立回报并附上 A2UI；跨 Bot 对话异步委托，后台可同步等待并释放名额；保留深度、配额、循环和用户隔离检查 |
| S17 | 断线与恢复 | 排队对话回落云端；已开始的 Mac 工作中断不自动重跑；指令和回报幂等，只有明确取消任务才级联取消 |

## 非功能需求

- 私有 skills：由平台 Pi Extension 提供创建、更新、按需加载、启停、删除与版本恢复；每个 Bot 只管理自己的，云端与 Mac 共用数据库。无用户管理界面、公开 Bot 字段或资料库文件；接口仅接受当前运行对应的智能体令牌，版本冲突返回 409。详见 [agent/README.md](../packages/agent/README.md)。

- API 单副本；Worker 用 `FOR UPDATE SKIP LOCKED` 认领、带租约，可多副本；每个 Worker 有 `PI_BOT_WORKER_CONCURRENCY`（默认 4）个后台名额和独立的 `PI_BOT_CONVERSATION_CONCURRENCY`（默认 4）个对话名额，同步委托的父子运行不会互相卡住。
- 设备签名时间偏差 ≤300 秒，nonce 不可重放；签名覆盖请求体。
- 服务商 API Key 用 vault 文件加密入库，vault 支持轮换；Key 不出现在日志和接口响应里。
- Runner 不接触数据库和 vault；容器只读、无 capabilities、限制内存和进程数。
- 错误响应统一为 `{detail}`，中文。
- 模型代理令牌默认 15 分钟（不低于 15 分钟），云端运行的令牌覆盖最长 30 分钟的运行时间。

## 自动化测试

`server/tests/integration.test.ts`（需要 `PI_BOT_TEST_DATABASE_URL`，会清空该库）：

- 管理员引导、创建用户和模型、普通用户无法访问后台、看不到模型细节、无模型时 503。
- Bot 按用户隔离、`slug` 唯一且改名不变。
- 模型代理：设备签名覆盖请求体、注入服务商 Key、改写模型名、用户令牌被拒、用量入账。
- Mac 在线：运行下发、幂等与连续消息排队、流式 `delta`、审批创建与决定、文件 RPC 与 504、停止、Mac 断开后文件接口 503。
- Mac 离线：经 Runner 和代理在云端运行，对话仅带调度、展示和私有 skill 工具，后台才带搜索和委托工具，没有文件或终端工具；长期记忆压缩并进入提示。
- 云端协作：对话异步转交，目标后台记录隐藏；结果触发发起方的新回报回合，不展示内部回报输入。
- 协作规则（Mac 执行）：自我委托、未知 Bot、其他用户的 Bot、令牌与运行不符被拒；成环、超深度、被委托方异步转交、互相等待、超过 5 个委托被拒；目标忙时排队、空闲后启动；长轮询；取消发起方后逐层级联取消。
- 两个用户互相看不到 Bot、消息、文件和 Mac 状态；Mac 中途掉线时运行失败并保留已生成文本。
- 管理员禁用用户、吊销设备。
- `server/tests/skills.test.ts`：skills 按 Bot 隔离、仅当前运行可管理、参考资料按需读取、版本冲突与恢复、真实云端 Extension 链路与公开记录过滤。

- `server/tests/async-tasks.test.ts`：两个后台任务与独立对话、第三项排队、指令幂等与投递、取消、隐私、A2UI 回报、Mac 掉线和等待释放容量。


### Always-on 验收

- 聊天可建立、查询、修改、暂停、恢复、完成和停止目标；没有进行中的目标时不自动检查。进度、检查点和重连唤醒均持久化。
- 仅兼容电脑在线时执行，目标检查不回落云端，也不委托其他智能体；断线续接保存进度，未确认副作用等待用户。
- 没有新进展保持静默，有进展的目标在现有时间线各发一条且不重复；等待不占执行名额，静默轮次不改变列表活跃时间。
- 检查可在目标授权范围内改文件和跑命令；控制版本、调用次数、每日八轮上限及失败退避由服务端执行。
