# Pi Bot Android 需求与验收

整体架构见 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 定位

手机是随身的 Bot 遥控器：看 Bot 们在干什么、给 Bot 发消息、批准访问请求、浏览 Mac 上的资料库、新建和编辑 Bot。手机本身不运行 agent，不配置模型，也没有本地数据库。

## 技术栈

- Kotlin 2.3、Jetpack Compose（Material 3）、Navigation Compose，minSdk 26。
- OkHttp 5（REST + 前台 WebSocket）、kotlinx.serialization、Coroutines/StateFlow。
- EncryptedSharedPreferences 保存会话。
- 角色：`face/` 是 `packages/bot-face` 的 Compose Canvas 移植，`spec.json` 在构建时复制进 assets。

## 功能需求

| 编号 | 需求 | 验收 |
|---|---|---|
| A1 | 用服务器地址 + 管理员创建的账号登录 | 地址可带路径前缀（如 `/pibot`）；debug 和 release 均支持 HTTP、HTTPS；错误密码、连不上服务器有中文提示 |
| A2 | Bot 会话列表：主 Bot 入场动画、搜索、名字、最近时间、状态一句话、待审批红点、Mac 在线状态 | 运行中显示「工作中…」（云端运行为「在云端思考…」），等审批显示「等你批准…」，失败显示「出错了」，空闲时显示最近一条消息的首行，3 天以上无活动显示「睡着了 · N 天」；下拉刷新；搜索名字与最近消息；窄屏列表与对话单页切换，宽度 ≥720dp 时左列表、右对话且高亮选中项；折叠与切换 Bot 保留草稿；Mac 离线时提示消息会在云端回复 |
| A3 | 新建 / 编辑 / 归档 Bot：名字、人设、模型、造型、颜色、深浅色 | 预览实时变化，可「随机换一个」；模型可选「跟随默认」；归档前二次确认 |
| A4 | 时间线：一条连续的对话，回复推送、Markdown（标题、列表、引用、代码、表格）、简短进度 | 启用私有 skills 时按完整模型消息推送，隐藏内部工具消息与管理说明；不显示工具执行标签，回答上方保留最多三句进度；滚到顶部加载更早消息；任务运行中仍可发送；输入区无停止按钮；通过聊天查询、补充和明确取消；小人旁显示一行动作或任务数量 |
| A5 | 审批卡片 | 显示 Bot 想访问的路径和理由；批准或拒绝后卡片消失、运行继续 |
| A6 | 资料库浏览（Mac 在线时） | 逐级进入目录、返回上一级；文本和 Markdown 预览、图片预览；Mac 离线时提示不可用 |
| A7 | 设置：账号、服务器、实时连接状态、Mac 设备与在线状态、修改密码、退出登录 | 新密码至少 8 位；退出后回到登录页 |
| A8 | 实时更新 | 前台时保持 WebSocket，断线退避重连并补拉；后台时断开；会话失效自动回到登录页 |
| A9 | Bot 之间的委托 | 后台委托的内部记录隐藏，结果在发起方时间线另发；发起方回复上方显示「交给了 X · 状态」标签；点击进入对方时间线 |

## 非功能需求

- 令牌只存在加密存储里；不保存密码。
- 界面中文，固定浅色主题；系统关闭动画（动画时长缩放为 0）时角色保持静止。
- 不依赖 Google Play 服务。
- 不提供 skills 管理界面；skills 由各 Bot 自管理，正文和参考资料不出现在公开 Bot 接口与资料库中。详见 [agent/README.md](../packages/agent/README.md)。

## 自动化测试

`./gradlew :app:testDebugUnitTest`：

- `PiBotFaceTest`：规格列表、Mulberry32、`avatarFor`、轮廓平滑、引擎逐帧数值与 TypeScript 参考值一致、减少动态效果、运行状态到表情的映射。
- `DomainTest`：时间线合并与 `delta`、运行中工具、状态一句话（含去掉 Markdown 标记）、服务器地址解析、Markdown 块与行内解析。
- `RepositoryTest`（MockWebServer）：登录与路径前缀、错误信息、Bot/消息/发送/流式合并/分页、编辑时总是带上 `model_id`、资料库路径编码与 503 提示、401 自动登出。

- 发送成功才清除已提交的草稿；失败保留输入与请求 ID；后台任务不禁用其他已完成消息的交互界面。聚合表情与状态读取 `activity`，不被最新短对话覆盖。


### Always-on 验收

- 所有 Bot 默认巡检，聊天可建立、查询、修改、暂停、恢复和停止长期委托；一次性、周期、任务完成与重连唤醒均持久化。
- 仅兼容 Mac 在线时执行，自动工作及子委托不回落云端；断线续接保存进度，未确认副作用等待用户。
- 无变化保持静默，重要结果在现有时间线幂等回报；等待不占执行名额，静默轮次不改变列表活跃时间。
- 默认巡检只读，授权委托沿用既有权限；控制版本、调用次数、每日轮次及失败退避由服务端执行。
